# Локальне оточення MySQL та phpMyAdmin

Цей репозиторій містить конфігурацію для швидкого розгортання СУБД **MySQL 8.0** разом із вебклієнтом **phpMyAdmin**.

## 🚀 Швидкий старт

### 1. Запуск сервісів
Щоб завантажити необхідні образи та запустити всі контейнери у фоновому режимі:
```bash
docker-compose up -d
```

### 2. Перевірка статусу контейнерів
Перевірити поточний стан запущених сервісів:
```bash
docker-compose ps
```

### 3. Перегляд логів
Щоб відстежувати логи роботи бази даних у реальному часі:
```bash
docker-compose logs -f mysql
```

### 4. Зупинка сервісів
Зупинити роботу контейнерів і звільнити мережу (дані бази даних зберігаються):
```bash
docker-compose down
```

> **Увага:** якщо потрібно зупинити сервіси з повним очищенням сховища даних (volume), додайте прапорець `-v`:
> ```bash
> docker-compose down -v
> ```

## 🔑 Реквізити та способи підключення

### 1. Через браузер (phpMyAdmin)
Відкрийте адресу: [http://localhost:8080](http://localhost:8080)
* **Сервер:** `mysql`
* **Користувач:** `dev_user` *(або `root`)*
* **Пароль:** `devpassword` *(для root: `rootpassword`)*

### 2. Через зовнішні клієнти (DBeaver, DataGrip, VS Code, застосунки)
* **Хост:** `localhost` (або `127.0.0.1`)
* **Порт:** `3306`
* **Назва бази даних:** `my_database`
* **Користувач:** `dev_user`
* **Пароль:** `devpassword`

### 3. Напряму через консоль контейнера
Виконання SQL-запитів безпосередньо в інтерактивній консолі MySQL всередині контейнера:
```bash
docker-compose exec mysql mysql -u dev_user -p my_database
```
*(Після введення команди вкажіть пароль: `devpassword`)*

## 📁 Збереження даних
Усі дані бази автоматично зберігаються в іменованому томі `mysql_data`. Створені таблиці, схеми та записи не видаляються при перезавантаженні системи або зупинці контейнерів.

---

## 🚕 Схема бази даних (Сервіс таксі)

У директорії `sql/` знаходяться DDL-скрипти для створення структури бази даних:

* `sql/01_create_table_street.sql` — створення таблиці вулиць (`street`).
* `sql/02_create_table_house.sql` — створення таблиці будинків (`house`) з геокоординатами та зовнішнім ключем на `street`.
* `sql/rollback/drop_tables.sql` — скрипт видалення таблиць у коректному порядку (спочатку дочірня `house`, потім батьківська `street`).
* `sql/seed/sample_data.sql` — тестові дані для перевірки зв'язків.

### Ручне застосування DDL-скриптів:
```bash
docker-compose exec -T mysql mysql -u dev_user -pdevpassword my_database < sql/01_create_table_street.sql
docker-compose exec -T mysql mysql -u dev_user -pdevpassword my_database < sql/02_create_table_house.sql
```
*(При першому запуску з чистим томом скрипти з папки `sql/` застосовуються автоматично завдяки монтуванню в `/docker-entrypoint-initdb.d`)*
